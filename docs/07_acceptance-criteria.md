# 受け入れ基準（完成したかの確認方法）

> 機能（F-xx）は [要件定義](01_requirements.md) を参照。自動テストは `test/api.test.js`

「自動」は `npm test` で確認できるもの、「手動」はブラウザで確認するもの。

| No | 確認すること | 関係する機能 | 確認方法 |
|----|-------------|-------------|---------|
| AT-01 | ログインすると、3列が表示される（DBが空なら空の列） | F-01, F-07 | 手動 |
| AT-02 | 「宿題」と入力して追加すると、「やること」列の一番下に出る | F-02 | 自動・手動 |
| AT-03 | 何も入力しない／空白だけで追加すると、M-01が出てカードは増えない | F-02 | 自動・手動 |
| AT-04 | 51文字目は入力できない。サーバーも51文字以上を受けつけない | F-02 | 自動・手動 |
| AT-05 | 「→」を2回押すと、やること → 進行中 → 完了 と動く | F-03 | 自動・手動 |
| AT-06 | 「完了」から「←」で「進行中」に戻る | F-03 | 自動・手動 |
| AT-07 | 「やること」に「←」、「完了」に「→」が出ていない。サーバーも飛びこえる移動を受けつけない | F-03 | 自動・手動 |
| AT-08 | 「×」→「キャンセル」でカードが残り、「×」→「OK」で消える | F-04 | 自動・手動 |
| AT-09 | 追加・移動・削除したあと、別のブラウザやスマホで開いても同じ状態が表示される | F-05 | 自動・手動 |
| AT-10 | パスワードを知らないと、画面もAPIも使えない | F-07 | 自動・手動 |
| AT-11 | サーバーを止めた状態で追加すると、M-04 が出て入力欄の文字が残る | F-08 | 手動 |
| AT-12 | `<b>テスト</b>` と入力すると、太字にならず文字のまま表示される | 非機能（安全性） | 自動・手動 |
| AT-13 | マウスを使わず、Tab と Enter だけで追加・移動・削除ができる | 非機能（使いやすさ） | 手動 |
| AT-14 | 画面幅を狭くすると、3列が縦にならぶ | 非機能（表示） | 手動 |
| AT-15 | 公開URLを HTTPS で開いて使える | 非機能（公開） | 手動 |
| AT-16 | `npm test` がすべて通る | 非機能（テスト） | 自動 |
| AT-17 | 「やること」に3枚あるとき、真ん中のカードで「↑」を押すと一番上に、「↓」を押すと一番下に動く。開きなおしても順番が同じ | F-09, F-05 | 自動・手動 |
| AT-18 | 一番上のカードに「↑」、一番下のカードに「↓」、「完了」のカードに「↑」「↓」が出ていない。サーバーも「完了」の並び替えを受けつけない | F-09 | 自動・手動 |
| AT-19 | Tab と Enter だけで、同じカードを続けて2回「↓」で動かせる | F-09, 非機能（使いやすさ） | 手動 |
