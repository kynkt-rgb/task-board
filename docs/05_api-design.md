# API設計

> データの形は [データ設計](04_data-design.md)、実装は `src/app.js`

## API仕様
すべてログインが必要（`/api/health` を除く）。データの形はJSON。

| メソッド | URL | 内容 | 送るもの | 成功 | 主なエラー |
|---------|-----|------|----------|------|-----------|
| GET | `/api/health` | 動いているかの確認 | － | 200 | 503 |
| GET | `/api/cards` | カード一覧 | － | 200 | 401 |
| POST | `/api/cards` | カード追加 | `{"title":"宿題"}` | 201 | 400（空・51文字以上） |
| PATCH | `/api/cards/:id` | となりの列へ移動 | `{"status":"doing"}` | 200 | 400（となりでない列）・404 |
| POST | `/api/cards/:id/reorder` | 同じ列の中で1つ上・1つ下と入れかえる（F-09） | `{"direction":"up"}`（`up` か `down`） | 200 | 400（向きがちがう・「完了」の列・すでに一番上／一番下）・404 |
| DELETE | `/api/cards/:id` | カード削除 | － | 204 | 404 |

返すカードの形：
```json
{ "id": 1, "title": "宿題", "status": "todo", "createdAt": "2026-11-01T09:00:00.000Z", "updatedAt": "2026-11-01T09:00:00.000Z" }
```
エラーのとき：`{"error":"タイトルを入力してください"}`
